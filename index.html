    Notes

    Where the numbers on this page come from.

    Measured, not typed

    Bounding boxes, volumes, plan outlines and wall thickness in assets/model.json come from reading the STEP files with build123d and shapely.

    Thin walls

    The blade is designed at 0.9 mm. The thinnest wall found in the plan sections is lower than that on some cutters, mostly at star points. Check the table before you slice.

    The set file

    The set STEP lays the three cutters out 95 mm apart for display. It is wider than the build limit on purpose. Print the single-cutter files.

    Open it locally

    This page loads JSON and ES modules, so serve the folder (for example python3 -m http.server) instead of opening the file directly.
